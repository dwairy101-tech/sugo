SUGO — النسخة المعدلة الجاهزة
=================================

إصدار الواجهة: 6.0.0-swiss-editorial
إصدار Worker المحفوظ: 4.1.0-ticket-title-accuracy
التاريخ: 2026-07-28

ما تم إصلاحه:
- إعادة تصميم جذرية لكل الواجهة بأسلوب Editorial Command Center مع الحفاظ على ألوان SUGO.
- جعل الصفحة متجاوبة فعلياً مع الكمبيوتر والتابلت والهاتف بدلاً من العرض الثابت.
- نقل البحث العربي/الإنجليزي إلى شريط القيادة العلوي وإضافة قائمة هاتف قابلة للفتح والإغلاق.
- توحيد تصميم الرئيسية وAsk AI وCreate Ticket وتحليل الصور والبحث والمقالات والإدارة.
- إضافة خطي Inter وAmiri المجانيين داخل المشروع؛ النص العربي يستخدم Amiri.
- ربط جميع عناوين التذاكر الرسمية وعددها 73 بالقالب الصحيح بالعربية والإنجليزية.
- فهم الصياغات الطبيعية مثل: بدي تذكرة عن... و create ticket about...
- تفضيل قالب Create Ticket نفسه بدل المقال العام عندما يشتركان في العنوان.
- استبدال الرد العام بخيارات محددة عندما يطابق العنوان إجراءين حقيقيين.
- تصحيح فهم كلمات عربية معرّفة مثل: البث.
- فصل نتائج Ask AI عن قوالب Create Ticket المخفية.
- تحسين فهم العبارات العربية العامية مثل: بدي أفتح وكالة، ما بقدر أفوت حسابي، انحظر حسابي، وما وصلني الشحن.
- منع قالب تذكرة ضعيف من تجاوز المقال الصحيح.
- تصحيح تقييم الثقة والحالات الغامضة.
- تحديث تعليمات الـWorker بحسب وضع Ask AI أو Create Ticket.
- جعل SOP Only الوضع الافتراضي في Ask AI وتحليل الصور.
- منع الادعاء بأن طلباً تم تقديمه أو أن الحساب تمت مراجعته من دون دليل.
- رفض الأرقام التي يضيفها مزود الذكاء الاصطناعي إذا لم تكن موجودة في الإجراء.
- إضافة محرك بحث عربي/إنجليزي عالي الدقة واختبارات دقة جديدة.

طريقة الرفع على GitHub:
1. فك ضغط الملف.
2. ارفع جميع الملفات والمجلدات الموجودة داخله إلى جذر مستودع GitHub واستبدل الملفات القديمة.
3. انتظر اكتمال GitHub Pages ثم افتح الموقع واضغط Ctrl+F5.

- إصلاح مطابقة العناوين موجود في ملفات GitHub، لذلك تحديث الـWorker وحده لا يكفي.

  تحتاج إلى تحديث Cloudflare مرة أخرى؛ هذا الإصدار يغيّر الواجهة وملفات GitHub فقط.
