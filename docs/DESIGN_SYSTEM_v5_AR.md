# نظام تصميم SUGO v5

الاتجاه البصري: **Editorial Command Center**

## ما بقي ثابتاً

- الألوان الأساسية: الأسود `#080809`، الأسطح الفحميّة، والعنابي `#941B31`.
- جميع بيانات المعرفة وعددها 284 موضوعاً.
- 73 قالب تذكرة مخفياً ومنطق المطابقة الدقيق في v4.1.0.
- Search وAsk AI وCreate Ticket وUpload Image والمفضلة والحديثة والإدارة.
- رابط Cloudflare Worker وإعدادات KV والمفاتيح.

## ما تغيّر

- واجهة رئيسية جديدة بتسلسل بصري واضح وشريط بحث علوي.
- نظام بطاقات وأسطر وحدود موحّد لكل مساحات العمل.
- تخطيط متجاوب:
  - ديسكتوب: ثلاثة أعمدة.
  - تابلت: لوحة النتائج تنتقل أسفل مساحة العمل.
  - هاتف: قائمة جانبية قابلة للفتح وتخطيط عمود واحد.
- مؤشرات تركيز واضحة للوحة المفاتيح وحالات Hover وReduced Motion.
- خطوط مجانية ومستضافة داخل المشروع:
  - Inter للواجهة الإنجليزية.
  - Amiri للنص العربي.

## الملفات

- التصميم الأساسي السابق: `css/styles.css`
- طبقة إعادة التصميم: `css/redesign-v5.css`
- منطق الواجهة مع البحث العلوي وقائمة الهاتف: `js/app.js`
