# نظام تصميم SUGO v6

## الاتجاه

اسم الاتجاه: **Swiss Editorial Index**

الواجهة مبنية كنظام فهرسة تحريري واضح، وليس كلوحة Dashboard تقليدية:

- خلفيات بلون الورق الدافئ.
- نص أسود عالي التباين.
- العنابي الأصلي لـ SUGO كلون أساسي للأفعال والحالات النشطة.
- شبكة دقيقة وحدود مستقيمة بدل البطاقات الدائرية المتوهجة.
- أرقام واضحة للأدوات والأقسام.
- عناوين كبيرة بتسلسل بصري قوي.

## الخطوط

- الواجهة الإنجليزية: Inter.
- المحتوى العربي: Amiri.
- الخطان مستضافان داخل المشروع ومفتوحا المصدر.

## الشاشات المشمولة

- الصفحة الرئيسية والفهرس المباشر.
- Search.
- Ask AI.
- Create Ticket.
- Upload Image.
- المقالات العربية والإنجليزية.
- Visual Guides.
- Favorites وRecent.
- قائمة المعرفة.
- لوحة الإدارة وتحرير المحتوى والصور والقوائم.

## الملفات

- الطبقة الأساسية: `css/styles.css`
- طبقة التصميم الجديد: `css/redesign-v6.css`
- البنية والتفاعلات: `js/app.js`

## التجاوب والوصول

- Desktop: ثلاثة أعمدة للفهرس والعمل والنتيجة.
- Tablet: قائمة جانبية قابلة للفتح مع بقاء لوحة النتيجة.
- Mobile: مساحة عمل واحدة مع عرض النتيجة فوقها وإمكانية الإغلاق.
- مؤشرات تركيز واضحة للوحة المفاتيح.
- دعم `prefers-reduced-motion`.
